# sommacampagna (VST3)

Headless JUCE VST3 prototype derived from the JSFX summing DSP concept.

Current status:
- 16 input channels (8 stereo stems) -> stereo output
- No custom GUI (Generic JUCE editor only)
- Core controls included:
  - Console Flavor
  - Compensated Drive (dB)
  - Power Supply Type
  - Master Output Gain (dB)
  - Gravity (%)
  - Summing Bypass
- BUS STRESS (RAIL SAG) exposed as parameter meter

## Build (Windows)

1. Install CMake and Visual Studio 2022 with C++ workload.
2. Clone/download JUCE locally.
3. Configure:

```powershell
cmake -B build -S . -G "Visual Studio 17 2022" -DJUCE_DIR="C:/path/to/JUCE"
```

4. Build:

```powershell
cmake --build build --config Release
```

The VST3 will be generated by JUCE in the build output tree.
